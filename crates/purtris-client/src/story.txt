# Puzzle Commons: the story script.
#
# Parsed at startup by story.rs. Format:
#   SCENE <id> <world backdrop 0-4>
#   RIGHT <speaker> <speaker> ...      (optional: who stands on the right; everyone else stands left)
#   <speaker> <expression> | <line>
#   END
# Speakers: the 19 cast ids (cast.rs), plus two voices with no body: "box" and "sena".
# Expressions: normal smile delighted angry sad shocked smug sleepy.
#
# The courier ("mira") is named and gendered by the player. "Mira" in a line becomes the chosen
# name. When someone talks ABOUT the courier, use the pronoun tokens, which follow the girl/boy
# choice: {she} {She} {her} (object: her/him) {his} {His} (possessive: her/his) {herself} {girl}.
#
# Write plain, complete, natural English. Every line must fit three rows of the dialogue box:
#   ./target/release/puzzle-commons --story-check <dir> 1920 [scene ids to render]
#
# When scenes play (app.rs):
#   prologue                before the first visit to the story map
#   wN_intro                arriving in world N
#   wN_nK                   before node K's match; wN_mid plays before node 2, wN_boss before node 5
#   wN_nK_win / wN_nK_lose  after the first win / first loss at node K (the loss line gives a tip)
#   wN_clear                after first beating the champion (node 5)
#   w4_fall, epilogue       after w4_clear
# Spoilers for everything: see docs/story/BIBLE.md.
